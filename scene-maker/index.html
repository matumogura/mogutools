4. 書き出し

使い方と注意

ココフォリアに入れる

  1. GM でルームに入る
  2. ルーム設定 →「ルームデータのインポート」で ZIP を選ぶ（盤面にドロップでも可）
  3. 「外部ツールで作成…」の確認は OK
  4. シーン一覧に並ぶ。小さい絵を押すと盤面に出る

直すとき

  • 「書き出した ZIP を開いて直す」で ZIP を開き、直して「上書き」で書き出す
  • ココフォリアから書き出した ZIP も開ける（前景は重ねたままの絵になる）

注意

  • BGM・効果音は入れられない
  • 画像は 1 枚 5MB まで
  • 素材（ZIP）は、ココフォリアの画像選択に入れたいとき用
  • 非公式ツール。ココフォリアの更新で使えなくなることがある

枠は前景フレームメーカー、動く素材は場面転換素材メーカーで作れます。
