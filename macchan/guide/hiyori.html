卓日和たくびよりの使い方

卓日和は、TRPG の卓の日程決めとメンバー募集のためのページです。Discord の Macchan Bot から始めることも、ブラウザだけで作ることもできます。答える人はログインなしで、丸を付けるだけです。はじめての人に渡すときは 卓日和の紹介ページ が向いています。やりたいことから選んでください。

1日程調整を作る

Discord から作るか、卓日和の画面から作ります。

Discord から作る

/日程作成 名前:11月の卓 メンバー:@まちゃ けん さくら 開始日:11/9
  • 公開用の URL がチャンネルに出ます。答える人はログイン不要です。
  • 主催者用の URL は、実行した方にだけ見える形で届きます。候補日の追加や削除はこちらから行えます。
  • メンバー: で呼んだ人は、先に表へ入れておけます。
  • 開始日: は 11/9 11月9日 2026-11-09 の形で指定できます。省くと今日からです。
  • 日にちだけでなく 昼・夜それぞれの参加できる時間 も、はじめから集めます。日にちだけでよいときは 時間帯: を「いいえ」にします。

卓日和の画面から作る

  1. 卓日和 を開き、Discord でログインして ＋ 新しく作る を押します。
  2. 日程の聞き方 を選びます：日にちを決める（候補日に 全・夜・昼・×）か いつごろかを聞く（候補月に ○ △ ×）。
  3. メンバーの募集 を選びます：募集しない／シナリオを決めて募集／候補から選んでもらう。
  4. 件名とコメントを入れ、候補日（候補月）を選んで この内容で作る を押します。
  • できたページの URL は 案内文ごとコピー で、ひとことを添えた形でコピーできます。スマホでは 共有する も使えます。
  • 主催者のページのいちばん上に、いまどこまで進んだか（URL を配る ▶ 答えてもらう ▶ 日を決める）が出ます。
  • 時間帯を集めないときは、「時間帯も調整する」をオフにします。

2Discord に知らせる

主催者のページの「Discord へのお知らせ」で、集まりの知らせをチャンネルに出せます。

/日程作成 から作ったときは、打ったチャンネルが最初から届け先になります。

日程が決まったとき 無料日が決まったら知らせます。
直前のアナウンス 無料1 週間前・前日・開始 1 時間前・開始時刻・当日の朝・連日のときの次回の集合時間から選べます。
誰かが答えたとき 有料回答が入ったら知らせます。
催促 有料まだ答えていない人に知らせます。

知らせの文面は有料プランで変えられます（種類の名前の横の鉛筆を押すと、文面の欄が開きます）。無料では決まった文で届きます。止めたい知らせは、種類ごとにオフにできます。

3いつごろかを聞く

まだ先の予定で、日にちまでは決められないときに使います。卓日和の画面から作ります（/日程作成 で作れるのは日にちの調整だけです）。

  • 候補は日にちではなく 候補月 です。月ごと か 上旬・中旬・下旬 で出せます。
  • 答える人は、候補月ごとに ○（行ける）・△（たぶん）・×（むずかしい） を押すだけです。もう一度押すと空欄に戻ります。
  • みんなの希望の表では、× がいちばん少なく ○ が多い候補月に 「有力」 の印が付きます。

日にちの調整に進む

  1. 候補月が絞れたら、表の左でチェックを入れて 日にちの調整に進む を押します。
  2. 同じ URL のまま、全・夜・昼・× で答えてもらう画面に変わります。

進んだあとも、参加者・コメント・シナリオの希望は残ります。候補月への答えは、表の上の 「候補月のときの答え」 で見返せます（だれがどの月に行けると答えていたかが、名前と候補月の表で出ます）。

4メンバーを募集する

シナリオの案内と参加希望の人の一覧が載ったページを作れます。X や Discord に URL を貼ると、シナリオ・人数・形式・ツール・日時などが入った画像つきのカードで出ます。

  • BOOTH の商品ページの URL を貼ると、サムネと名前が入ります。卓日和は画像を預からないので、使えるのは BOOTH の商品画像だけです。
  • システム・KP・募集人数・概要・注意を書けます。「PL として KP と PL を募集」の形にもできます。
  • 形式（ボイセ・半テキ・テキセ）・ツール（Discord・ココフォリアなど）・想定時間・日時の目安・募集範囲（相互フォロー・フォロワー・だれでも）も選べます。どれも「その他」に自由に書けます。
  • 主催者のページの 募集画像を作る で、X などに貼れる募集の画像（PNG）を作れます。スマホでは共有、パソコンでは保存です（BOOTH のサムネは画像に入りません）。

参加する人・募集する人

  • 参加したい人は 参加希望 を押して、名前と参加できる日（候補月）を入れます。ログインは要りません。
  • 募集者は、来てもらう人に 「決定」 の印を付けられます。「受け付ける」をオフにすると締め切れます。
  • 「フォロワーに募集を表示」 をオンにすると、あなたをフォローしている人のマイページと、あなたの公開カレンダーのページにも、その募集が並びます（はじめはオフ。オフのあいだは、URL を知っている人しか見られません）。

5シナリオの候補から選んでもらう

「どれを回すかは、集まった人と日程で決めたい」ときに使います。

  • 候補は 2〜6 つ 出せます。それぞれに募集人数・ひとこと・BOOTH の URL を付けられます。
  • 参加する人は「やりたいシナリオ」をいくつでも選べます。
  • 主催者のページには、候補ごとに 希望した人 と、その人たちの 都合が合う日（候補月） が並びます。人数が足りていて日程も合うものには「成立しそう」と出ます。

決める

  1. 候補のカードで 名前を押して来てもらう人を選びます（はじめは希望した人が全員選ばれています）。
  2. 日（候補月）を押して選びます。
  3. 下のボタンを押します。
    • このシナリオの日程調整を作る … その候補だけを、選んだ人で 別の日程調整 として作ります。元の募集は残るので、ほかのシナリオも続けて決められます。
    • この募集ごと、このシナリオに決める … 募集ぜんたいを、そのシナリオ 1 つに決めます。「決め直す」で戻せます。
  • 別の日程調整として作ると、選んだ人が「決定」の状態で入ります。候補月を選んでいれば、その月の日が候補日になって、日にちの調整から始まります。候補月への答えも引き継ぎます。
  • 作った先は、元の募集のカードの「日程調整を作成済み」から開けます。この行き先が見えるのは主催者だけなので、来てもらう人には URL を送ってください。
  • 別に作った日程調整も、作れる数に 1 件として数えます。
  • 「いつごろかを聞く」と組み合わせて、候補月とシナリオを一緒に聞くこともできます。
ヒントキパビューの本棚でシナリオを 2〜6 つ選んで「募集する…」を押すと、選んだシナリオが候補に入った状態で、この形の募集を作れます。

6一緒に組みたくない人

メンバー募集では、参加する人が、同じ募集のほかの参加者に「一緒に組みたくない」の × を付けられます。

  1. 参加希望を出したあと、答える画面の 一緒に組みたくない人 を開きます。
  2. ほかの参加者が並ぶので、名前を押すと × が付きます。もう一度押すと外れます。
  • × を付けたことは、相手やほかの参加者には見えません。主催者にも、だれが付けたかは見えず、「この 2 人は一緒に組めない」とだけ伝わります。
  • × の付いた 2 人は、主催者でも 同じ卓に組めません（「決定」にする・シナリオの日程調整を作る・この募集ごと決める、のどれも止まります）。
  • 選べるのは、参加希望を出した端末 か、ログインして「マイページの『参加希望』に表示」にしたアカウント からだけです。
  • × はその募集の中だけのものです。参加をとりやめたときや、日程調整が消えたときに、一緒に消えます。

7カレンダーと公開

マイページのカレンダーには、開催の決まった日と、まだ調整中の卓の候補日が、卓の名前で並びます（調整中は点線の枠）。

1 日に入りきらないときは「ほか○件」と出るので、日を押して下の一覧で見てください（スマホでは、日の中は色の印だけになります）。

カレンダーを公開する

マイページのカレンダーの下の カレンダーを公開する から、自分の予定を見せるページを作れます。

  • できた URL を知っている人は、ログインなしで 見られます。
  • 出るのは 開催の決まった日 です。「調整中の候補日も表示」 にすると、まだ日の決まっていない卓の候補日も点線で出ます（はじめはオフ）。ログインして参加している卓は、名前を出さず「調整中」とだけ出ます。ほかの参加者の名前は出ません。
  • 表示のしかたは 「予定あり」とだけ表示（はじめはこちら）か 卓の名前も表示。表示する名前も変えられます。
  • ほかの人にどう見えるかは、カレンダーの上の 公開プレビュー で確かめられます。自分用（全部） で戻ります。
  • 同じ場所に、あなたをフォローしている人の名前が並びます。
  • 公開をやめる で、いつでもやめられます。配った URL は開けなくなり、もう一度公開すると新しい URL になります。

8フォロー

気になる人の公開カレンダーをフォローしておくと、その人の募集をまとめて見られます。

フォローして「フォロー中の募集」を見る

  • 相手の公開カレンダーのページで フォローする を押します（Discord でのログインが要ります）。
  • 相手が「フォロワーに募集を表示」にした受付中の募集が、「フォロー中の募集」 のページに並びます。マイページの入口か、メニュー（≡）から開きます。
  • 前に見たあとで増えた募集には 「新着」 が付きます（見たかどうかは、その端末で覚えます）。
  • だれがフォローしているかは、相手に名前で見えます。ほかの人には見えません。
  • やめるときは、相手のページの「フォロー中」をもう一度押すか、「フォロー中の募集」のページで名前の右の × を押します。

つながっている人を日程調整に追加する

主催者は、フォローでつながっている人（自分がフォローしている人・自分のフォロワー）を、押すだけで参加者に入れられます。

  • 追加できるのは、相手が「自分の設定」の 「日程調整への追加」 を許可しているときだけです（はじめはオフ）。
  • 主催者のページの「フォローでつながっている人を追加」に、追加できる人が並びます。名前を押すと表に入ります。
  • 入った人の回答には、確定済みの予定と被る日の × が自動で入ります。有料プランの人は、「自分の設定」の名前・フリカレ・参加できる時間も使われます。
  • 追加された人のマイページには「追加されました」と出ます。本人が回答を直すことも、とりやめることもできます。
  • Discord の /日程作成 で @ で呼んだ人も、その人のアカウントに結ばれます（ログインするとマイページに出ます）。

9予定が被る日は自動で ×

ある卓の日が確定すると、あなたが参加しているほかの日程調整にも、その予定が自動で反映されます。

  • 対象は、ログインして「マイページの『参加希望』に表示」にしている 日程調整の、あなたの回答だけです。ログインせずに答えたものは変わりません。
  • 昼も夜も被る日は × になります。夜だけ被る日は「全」が「昼」に変わる、というように、空いている時間帯は残します。
  • 昼の卓と夜の卓は、同じ日に両方入れられます。時間帯も調整している卓どうしは、開催する時間が重なるときだけ「被り」とみなします（13〜18 時の卓と 21〜24 時の卓は被りません）。
  • 昼も夜も揃っている日は、主催者が帯を選ぶまで反映されません。主催者が表の 全・夜・昼 のマスを押して帯を選ぶと、そこで反映されます。
  • 手で入力してあった日も書き換わります。入力画面では、自動で直した日に「被」の印が付きます。自動で直ったあとに自分で入れ直した日は、それ以上は書き換わりません。
  • 確定が外れたり、その日程調整が消えたりすると、元の回答に戻ります。
  • メンバー募集では、「決定」の付いた人がいるとき、決定の付いた人の予定だけに反映されます。

10終わったら片づける

主催者のページのいちばん下の 終了済みにする で、終わった日程調整を片づけられます。

  • マイページの「作った日程調整」「自分の募集」には並ばなくなり、下の「終了済み」にまとまります。作れる数にも数えません。
  • 消えるまでは、マイページのカレンダーやキパビューに出続けます。ページも開けるので、確定した日の一覧はそのまま見られます。
  • 終了済みのあいだは、回答や設定は変えられません。メンバー募集は締め切った扱いになります。
  • 元に戻す で、いつでも戻せます（作れる数に空きが要ります）。
ポイント作った日程調整は、最後の候補日（候補月で聞いているあいだは最後の候補月）の 1 か月後に自動で消えます。ためこまずに済みます。

11自分の設定

Discord の /個人設定 で出るリンクか、卓日和のメニューから「自分の設定」を開きます。

  • 日程調整の表に表示する 名前 を決められます。
  • フリーカレンダー の公開 URL を覚えさせておくと、予定を自動で取り込めます（取り込みは無料でも使えます）。手で入力した日は、フリカレの取り込みで上書きされません。
  • ふだんの都合 では、フリカレの空欄をどう読むか（予定がない日は参加できる、など）を決められます。
  • 有料プランの方は、/日程作成 で @ で呼ばれたときに、ここの名前・フリカレ・参加できる時間がそのまま入ります（登録だけなら無料でもできて、有料にした日からそのまま効きます）。
  • 日程調整への追加 を許可すると、フォローでつながっている人があなたを日程調整に入れられます。
  • 登録を消す で、登録した内容をまるごと消せます。

12有料プラン

卓日和の有料プランは 人（Discord アカウント） に付きます。無料でも日程調整とメンバー募集は使えます。

卓日和の有料プラン
付く先人（Discord アカウント）
コードHIYO-XXXX-XXXX-XXXX。Macchan Bot の PRO を引き換えた方にも付きます
作れる日程調整10 件 → 100 件（終了済みにしたものは数えません）
参加者10 人 → 100 人
そのほか@ で呼ばれたときに「自分の設定」がそのまま入る。Discord へのお知らせに「答えたとき」と「催促」が増え、文面も変えられる
入れる場所卓日和 の「プラン」

Macchan Bot の PRO（MACC-・サーバーに付く）は Macchan Bot のガイド をご覧ください。

?そのほか・困ったとき

  • 左上の ≡ を押すとメニューが開きます。いま見ているページの見出しと、マイページ・新しく作る・フォロー中の募集・通知の一覧・自分の設定が並びます。パソコンでは、上の帯にもマイページ・新しく作る・フォロー中の募集・通知の一覧が並びます。
  • 卓日和の入口やメニューの Bot を導入する から、Macchan Bot を自分のサーバーに追加できます。
  • 卓日和のどの画面の下にも、プライバシーポリシー・利用規約・お問い合わせへのリンクがあります。

使い方の質問、要望、不具合の報告は、サポートサーバーでお気軽にどうぞ。
