# シーンメーカー（mogutools 版）

背景の画像をまとめて入れると、ココフォリアの「シーン」を一括で作り、ルームデータ（ZIP）で書き出すツール。

元にしたツール: [shiki365/scene-maker](https://github.com/shiki365/scene-maker)（MIT License, Copyright (c) 2026 shiki365。`LICENSE.txt`）

## 元のツールから変えたところ

- 見た目を mogutools のトップページに合わせた（クリーム色の背景、紺の文字、Zen Maru Gothic、角の丸い部品）。明るいテーマだけ
- 日本語だけにした（`i18n.v1.js`・`lang.*.v1.js`・`theme.v1.js` を外した。`app.v1.js` の `t()` は `{n}` などを埋めるだけ）
- ヘッダー・フッターのリンクを mogutools 向けにした。OGP 画像は付けていない
- 文字を 2px 大きくし（本文 15px）、説明文を短くした。細かい注意は「使い方と注意」に折りたたんだ
- **書き出した ZIP を開いて直せる**（v1.1-mogu）
  - 書き出しの「あとで直せる情報を入れる」（最初からオン）で、ZIP に `scenemaker/project.json` と、重ねる前の前景（`scenemaker/<hash>.<ext>`）を入れる。ココフォリアは `__data.json` の `resources` にあるファイルしか読まないので、このフォルダは読み込みに影響しない（はず。ココフォリアで読み込めなくなったら、このチェックを外す）
  - 「書き出した ZIP を開いて直す」でこの情報を読むと、共通の前景・共通のマーカーも含めて元の作業に戻る。シーンの ID も戻るので、書き出しは「上書き」になる
  - 情報の無い ZIP（ココフォリアから書き出したルームデータなど）は、`__data.json` のシーンから組み立て直す。前景はシーンごとの画像（重ねてあればそのまま）になり、「重ねる」はオフになる。ZIP に無い画像は URL から取りにいくが、取れないものは抜ける
- **ココフォリア風の配置**（v1.2-mogu）: 上にバー、左に大きな盤面（背景をぼかして全体に敷く）、右に暗いシーン一覧。一覧の行の ✎ でシーン編集、⧉ で複製、🗑 で削除。「シーン編集」「素材・設定」「書き出し」は盤面と一覧の間に開く引き出し（`layout.v1.js`。開いていた引き出しは localStorage の `mogu-scene-maker.drawer` に覚える）
- 盤面の見本の画像は描き直しても同じ要素を使い回すので、動く画像（APNG・動く WebP・GIF）のマーカーが編集のたびに頭から戻らない
- ZIP を開くとき、ルームの今の盤面（`entities.room` の背景・前景・マーカー）も「いまの盤面」というシーンとして読み込む（v1.3-mogu）。ココフォリアでは今の盤面のマーカーはルームにあり、シーンには「盤面を保存」した分しか入らないため。シーンを選び直すと、マーカーがあれば「全体」の表示から始まる
- ZIP のスクリーンパネル（`entities.items` の `active` なもの。`closed` なら `coverImageUrl`）も読み込み、どのシーンでもマーカーの上に重ねて見せる（v1.4-mogu）。見るためだけで、動かせず、書き出しにも入らない（ルームのパネルを上書きしないため）。盤面右上の「パネル」で出し入れ（localStorage の `mogu-scene-maker.view-items`）

ほかの機能（マーカーパネル・テンプレート・縮小・素材 ZIP・自動保存など）は元のまま。保存の名前（localStorage・IndexedDB の `ccf-scene-maker*`）も元のままなので、元のツールで保存したプロジェクトファイル・テンプレートファイルを読み込める。
