How to use Macchan Bot

Macchan Bot is a Discord dice bot packed with everything you need to run a tabletop RPG session, centered on Call of Cthulhu (CoC). It handles dice, random tables, investigator creation, voice-channel controls and even scheduling. It also supports BCDice, so you can roll for other systems such as Call of Cthulhu 7th edition, Sword World and Shinobigami. Pick what you want to do below.

1Getting started

Add the bot to Discord, then type / or just write in the chat.

Add the bot

Open Add Macchan Bot to Discord and choose how to add it.

Add to serverAdds the bot to a server. Everyone on the server can use it.
Add to My AppsAdds the bot to your own account. You can use the main commands (/dice /choice /echo /help /gacha /pcmake /insanity /table /char /profile) even in servers without the bot and in DMs. /table and /char then use your own tables and your My Apps character.

User ID: 546059094537011211

Two ways to use it

  • Slash commands: type / to see the list. Each field shows a description, so type / whenever you are unsure.
  • Plain messages: the bot also reacts when you simply write 1d100 or 80 spot.
TipCommand names follow your Discord language: 日本語, English, 简体中文, 繁體中文 or 한국어. You can always search by the English name, so /dice works in any language.

2Rolling dice

Use /dice or just write the roll. The bot tells dice, skill checks, success checks and plain maths apart from how you write them.

WriteWhat it does
1d100 2d6+3Normal dice, or dice with maths
80 spot 80 目星Skill check with a two-digit skill value and a skill name (also shows critical, fumble, 1/2 and 1/5)
1d100<=60 #spotSuccess check with a target. Add the skill name as #spot or 【spot】
1d100>80 【growth】Checks with comparison signs (<= < >= >)
1d3*2+2*(4+5) 1+1Arithmetic, brackets and dice together. Also works as a calculator
d66D66 (two six-sided dice read as a two-digit number)
res50-30Resistance roll (active 50, passive 30)
siz13Gives a rough height from a SIZ value

If you leave out expr:, /dice rolls 1d100.

TipLetters and spaces can be half-width or full-width. Only skill names that start with a full-width character (such as Japanese) can follow the number without a space, as in 80目星. For English, put a space: 80 spot.

Talking to the bot (chat mode)

  • @Macchan ...?: answers with "maybe so" or "maybe not"
  • Greetings in Japanese such as こんにちは (hello), おやすみ (good night) and またね (see you): greets you back
  • Anything else: rolls some dice for fun

3Secret rolls

Put s in front of a roll, or use /secret, and only the person who rolled gets the result.

  1. Write s1d100, s80 spot or s1d100<=60 #spot (your message is deleted to hide it). You can also use /secret content:. Text that is not a roll becomes a secret message.
  2. A notice that someone made a secret roll appears in the channel. Only the roller gets the result.
  3. To reveal it, press 🔓 Reveal on the notice. The result is posted in the channel.
PointOnly the person who rolled can press the button. If someone else presses it, they just see a message that only the roller can use it.

How results are delivered (per server)

Choose this in the Macchan Bot console under 秘匿ロール (Secret rolls) → 結果の届け方と公開のしかた (Delivery and reveal).

Reveal with a channel button
Default		The result goes to your DMs. Reveal it with 🔓 Reveal in the channel.
No DMsNothing is sent by DM. Press 👁 See result in the channel to see it privately (as many times as you like). With /secret, the result is shown to you privately right away.
Reveal with 🔓 in DMsThe older style. The result goes to your DMs, and pressing the 🔓 on that DM reveals it.

If your DMs are closed, the default setting automatically switches to "No DMs" for you, so you can still roll.

4Other game systems (BCDice)

Macchan supports BCDice, so you can use the same commands as CCFolia and other tools. It is free on every plan.

Commands that work with no setup

Well-known commands that no other system uses are detected automatically. The system used is shown under the result, for example "Double Cross (auto)".

WriteSystem
3B6 3R6 3U6 C(1+2) x3 2d6Same in every system (generic dice)
CCB<=60 RESB(10-5)Call of Cthulhu (6th edition)
CC<=60 CC(1)<=60 CBR(50,60)Call of Cthulhu 7th edition
K20+5@10Sword World 2.5
10DX+3@8Double Cross
1NC NMNechronica
SG>=5 MTShinobigami
4SK HOTStellar Knights
ATMagicalogia

Commands such as ST (scene table), DT, FT, BT and RTT mean different things in different systems, so they are not detected automatically. Roll them in a channel where a system is chosen (see "Choosing a system" below), or pick the system in the system field of /dice. Rolls Macchan already understands, such as 1d100<=60 and 80 spot, are still answered by Macchan as before.

Examples

  • CC<=60 spot: Call of Cthulhu 7th edition skill roll → 【spot】 Hard success
  • K20+5@10 #knife: Sword World 2.5 power table
  • ST: scene table for Shinobigami or Insane (in a channel with that system chosen)
  • sCC<=40: put s in front to make it a secret roll

Add a skill name after a space, or as #spot or 【spot】.

Choosing a system Server admins

Choose it in the Macchan Bot console under ダイスシステム（BCDice） (Dice system).

System for this serverPick one system for the whole server. The default is none. You can search by part of the name or by its English name.
When no system is chosen"Detect well-known commands automatically" (default) or "Macchan dice only". If Macchan and another dice bot both answer, choose "Macchan dice only".
Per-channel systemsIf a CoC table and a Sword World table share a server, you can choose a different system for each channel. Threads use their parent channel's system.
When Macchan and BCDice overlapMacchan first (recommended): results look as before, and only commands Macchan does not know, such as CC or K20, go to BCDice.
BCDice first: even 1d100<=60 is judged by that system's rules (for example Hard success in 7th edition).

Popular systems appear at the top of the list: Call of Cthulhu, Call of Cthulhu 7th edition, Sword World RPG / 2.0 / 2.5, Shinobigami, Insane, Double Cross The 2nd and 3rd Edition, Nechronica, Magicalogia, Stellar Knights and Futari Sousa. You can also choose from the 300+ other systems in BCDice.

TipEach system has its own commands. Type /dice expr:help to see, privately, how to use the system set for that channel. If you choose a system in the system field of /dice, you can roll any system anywhere, including channels with no system and DMs.

6Your own tables (My Tables)

Register your own tables, then roll them with /table or just by typing the table's name.

  1. Create a table under マイ表 (My Tables) in the Macchan Bot console.
  2. Type the table's name, or roll it with /table name: times: (1 to 10 times).
  3. If you set it on a server where you have admin rights, other members on that server can roll it too.
  • A table belongs to the person who made it. If you add the bot to My Apps, you can roll your tables in servers without the bot and in DMs.
  • If you give a table the same name as a built-in one (一時的狂気 不定の狂気 冬の狂気 おみくじ 誕生日), your table is rolled instead (handy for house-rule madness tables).
  • Put 【秘】 at the start of an entry to send that result only to the roller. Wrap text in ||like this|| to hide just that part. Delivery follows the secret roll setting.
  • Write @サーバー主 in a result to notify the person who made the table.
  • A server cannot have two tables with the same name.
Free1 table, 10 entries per table, 100 characters per entry
Paid PRO10 tables, 500 entries, 2,000 characters (limits are per person)

Your tables are not deleted when your support ends. Only your oldest table stays usable; the rest are paused and come back when you support again.

7Creating and registering investigators

Roll characteristics to create an investigator. Once registered, just type a skill name to roll with your own skill value.

Rolling characteristics

Use /pcmake, or write キャラ作成 (also PC作成 キャラ生成). It rolls CoC 6th edition characteristics and can export them as a CCFolia piece.

Registering a character

  1. Open the character page (in Japanese) and log in with Discord. No admin rights are needed, so share this URL with your players.
  2. Paste the "Export for CCFolia" (ココフォリア用に出力) output from Iachara or Character Hokanjo. (A piece copied inside CCFolia only contains the name.)
  3. Check the skills and characteristics it read, then register.
  4. Next to the name list, choose the servers to use the character on.
  • Registered characters go into your "stock". It is fine to have characters not set on any server.
  • You can use one character per server. The same character can be set on several servers.
  • Pasting a character with the same name replaces it. Your stock holds 1 character on the free plan and 5 with PRO. 30 days after PRO ends, characters beyond the first are deleted (your oldest one is kept).
  • You can set characters on servers where you have admin rights. Set one on "My Apps" to use it with /char in servers without the bot and in DMs PRO.

Rolling and changing stats

WriteWhat it does
目星 (the skill name)Rolls with your registered skill value. If there are two or more matches, such as 芸術 (Art), the bot asks which one
目星-20 目星+10 目星/2One-off modifiers (not saved)
:HP-3 :SAN-1d3 :MP+2Raise or lower HP, MP or SAN. Values stay between 0 and the maximum. Lowering SAN also lowers checks that use SAN
/char input:Does the same as a command (no colon needed, as in /char HP-3). With no input, it privately shows your current status, characteristics and skills

HP, MP and SAN changes are saved to the character itself (the same values on every server it is set on). To remove a character, open the character page from the link shown by /profile.

CautionSkill names are checked before tables such as fortunes. If you have a skill with the same name as a table, the skill is rolled. If this clashes with another dice bot, you can turn off just the message input in server settings (/char still works).

8Voice channel and channel controls

Move people in and out of session rooms, and disconnect or mute voice channels in one go.

CommandWhat it does
/come user: /bye user:Lets a member into this room or removes them (they do not need to do anything)
/vc kaisanDisconnects everyone in the voice channel you are in
/nero member:Disconnects the chosen member from voice
/vc secret action: member: channel:Secret voice (mutes). With a target, only that person; without, everyone in the voice channel. Without a channel, the one you are in
/panel invitePosts an invite button that lets whoever presses it into the chosen channel
/panel roleCreates a role panel that gives a role when pressed

Voice controls need the bot to have the Move Members permission. Features that change channel access or roles need Manage Channels or Manage Roles.

Automatic features

For each one, choose the target voice channels and where notices go in the Macchan Bot console.

🔔 Voice noticesWhen a call starts in a voice channel, posts an invitation notice (and another when it ends). Notices can go to one shared channel, a channel per voice channel PRO, or a channel with the same name as the voice channel. Target voice channels can be chosen by a symbol in the name (🔔 by default), by picking them, or all of them. You can also choose the mention when a call starts (@everyone / @here / a role / none) and whether to post when it ends.
🕛 Good-night noticeAt midnight, posts a good-night message for people in the target voice channels (chosen by the 🕛 symbol by default).
💤 Auto disconnectAt a set time (2:00 Japan time by default), disconnects everyone in the target voice channels. A warning is posted 5 minutes before; press ⏰ to extend by 30 minutes (up to twice a night). Off by default.

On servers with no settings, calls in voice channels with 🔔 in the name are announced with @everyone in a channel named 🔔ボイチャお知らせ. If PRO ends, your per-channel mapping is kept; it just falls back to the shared-channel behaviour.

9Reminders and breaks PRO

Posts a reminder in this channel at the time you set. Works on PRO servers, or anywhere if you have PRO yourself.

CommandWhat it does
/remind set when: content:Write the time as, for example, 明日 21:00 (tomorrow 21:00), 10/15 21:00, 30分後 (in 30 minutes) or 来週 (next week). Where the bot is not present, it arrives by DM
/remind break length:Posts that you are on a break until the given time, then announces when it is time to start again. For breaks of 30 minutes or more, also warns 5 minutes before
/remind listShows your reminders so you can cancel them

You can change the wording in the console.

10Scheduling sessions (Takubiyori)

Takubiyori (卓日和) finds session dates and recruits players. Start it from Discord; people answering just tick days in the browser, with no login.

/sched title:November session members:@macha ken sakura start:11/9
  • A public URL is posted in the channel. The organiser URL is sent only to you.
  • /profile opens your own settings page for characters and scheduling.
  • The Takubiyori site is in Japanese only.

11Server settings

Server admins

Turn each feature on or off and choose who can use it.

  1. Open the Macchan Bot console (in Japanese) and log in with Discord (you need the Manage Server permission).
  2. Choose a server to see the list of features. Use the switch to turn a feature on or off, open 詳細 (Details) to change what it reacts to, who can use it and other options, then press 保存する (Save).
  • If Macchan and another dice bot both react, you can turn off only the overlapping features. For example, stop dice in plain messages but keep /dice.
  • The BCDice system and how secret rolls are delivered are also set here.
  • Type /config in Discord to check the current settings.

?Troubleshooting

The bot does not react when I write a roll
Dice may be turned off in the server settings, or limited to /dice only. Check with /config. /dice always works.
Macchan and another dice bot both answer
In the console, turn off message input for the overlapping features. BCDice auto-detection stops if you set "When no system is chosen" to "Macchan dice only".
ST (scene table) does not roll
ST differs between systems, so it only rolls in channels with a system chosen. You can also choose the system in the command, as in /dice expr:ST system:Shinobigami.
I cannot see my secret roll result
If your DMs are closed, nothing arrives by DM. If the channel notice has 👁 See result, you can see it there.
I typed a skill name and a skill was rolled instead of a table
Once you register a character, skill names are checked before tables. See Creating and registering investigators.
