差分一括登録ブックマークレット

ココフォリアにアップロードした画像を、ファイル名をそのまま差分名にして駒へ一括登録します。Chrome拡張は不要で、PC・iPad・スマホのどれでも使えます。

iPhone / iPad の方へ
「ファイル」アプリからこのページを開くとプレビュー表示になり、ボタン類が反応しないことがあります。 その場合も下の黒枠のコードを1回タップすれば全体が選択できますので、そのままコピーしてください。ボタンは使いません。

2ブックマークに登録する

iPhone / iPad（Safari）

  1. Safariで適当なページを開き、下部の共有ボタン（↑）→「ブックマークを追加」。名前を 差分一括登録 にして保存
  2. ブックマーク一覧（📖）を開き、右下の「編集」をタップ
  3. いま作った 差分一括登録 をタップして開く
  4. URL欄の中身をすべて消して、コピーしたコードを貼り付けて保存
  5. 使うときは、ココフォリアのルームを開いた状態でアドレスバーに 差分一括登録 と入力し、出てきたブックマーク候補をタップ
貼り付けたときに先頭の javascript: が消えてしまうことがあります。消えていたら手で足してください。ここが一番つまずきやすいポイントです。

Android（Chrome）

  1. 適当なページで ⋮ → ☆ でブックマークを作る
  2. ブックマークを編集し、名前を 差分一括登録、URLをコピーしたコードに書き換えて保存
  3. 使うときはアドレスバーに 差分一括登録 と入力し、出てきた候補をタップ
Androidではブックマーク一覧からタップしても動きません。かならずアドレスバーから名前で呼び出してください。

PC（Chrome / Edge / Firefox）

⇧ 差分一括登録

このボタンをブックマークバーへドラッグ＆ドロップするだけで完了します。

ドラッグがうまくいかない場合：

  1. ブックマークバーの空いている場所で右クリック → 「ページを追加」
  2. 名前に 差分一括登録、URL にコピーしたコードを貼り付けて保存
ブックマークバーが出ていないときは Ctrl+Shift+B（Macは ⌘+Shift+B）で表示できます。

3使いかた

  1. 差分書き出しツールのZIPを解凍し、PNGを全部ココフォリアのルームにアップロードする
  2. そのルームを開いたまま、登録した 「差分一括登録」ブックマークを実行する
  3. 画面下にパネルが出ます
    • 登録先の駒 … 既存の駒を選ぶか「＋ 新しい駒を作る」
    • ファイル名の絞り込み … 既定は @（書き出したPNGは @微笑み.png のような名前なので、これで他の画像が混ざりません）
    • 並び順 … ファイル名順／アップロードが新しい順／古い順
    • 置き換え / 末尾に追加 … 既存の差分をどうするか
    • 先頭の画像を立ち絵にする
  4. サムネイル一覧で確認して「登録する」
差分名はファイル名から拡張子を除いたものになります（@微笑み.png → @微笑み）。

4うまくいかないとき

症状対処
実行しても何も起きないブックマークのURLの先頭が javascript: になっているか確認してください
「内部データが見つかりません」ルームを開いた状態で実行してください。ページを再読み込みしてから再実行してみてください
画像が0件一度ルームの画像アップロード画面を開いてから、もう一度実行してください（画像一覧の読み込みが始まります）
目的の画像が出てこない絞り込み欄を空にしてみてください。別のルームにアップロードした画像は対象外です
登録が失敗するその駒を操作する権限がない可能性があります（他人の駒はGM権限が必要です）
このページのボタンが押せないiPhone/iPadの「ファイル」アプリのプレビューではボタンが動きません。コード枠をタップして全選択→コピーで進められます
v0.1です。まずはテスト用のルームでお試しください。ココフォリア本体の更新で内部構造が変わると動かなくなることがあります。
