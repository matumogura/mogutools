Macchan Bot の使い方

Macchan Bot は、クトゥルフ神話TRPG（CoC）を中心に、卓を回すのに必要なものをひととおり詰め込んだ Discord のダイスボットです。ダイス・各種表・探索者の作成・VC の操作から日程調整まで扱えます。BCDice にも対応しているので、新クトゥルフ・ソード・ワールド・シノビガミなど、ほかのシステムのダイスも振れます。やりたいことから選んでください。

1はじめに

Bot を Discord に入れて、/ を打つか、そのまま書き込むだけで使えます。

Bot を入れる

Macchan Bot を Discord に追加する から、入れ方を選びます。

サーバーに追加Bot をサーバーに入れます。サーバーのみんなが使えます。
マイアプリに追加自分のアカウントに追加します。Bot のいないサーバーや DM でも、主なコマンド（/ダイス /チョイス /代弁 /ヘルプ /ガチャ /キャラ作成 /狂気表 /マイ表 /マイキャラ /個人設定）が使えます。/マイ表 /マイキャラ は、自分の表・マイアプリ用のキャラクターが対象です。

ユーザーID：546059094537011211

使い方は 2 通り

  • スラッシュコマンド … / を打つと一覧が出ます。入力欄ごとに説明が出るので、迷ったら / を打って確かめてください。
  • メッセージ入力 … 1d100 や 80 目星 のように、そのまま書き込んでも反応します。
ヒントコマンド名は日本語で出ますが、英語名でも検索できます。/dice と打てば /ダイス が出ます。表示はお使いの Discord の言語設定に合わせて、日本語・English・简体中文・繁體中文・한국어 に切り替わります。

2ダイスを振る

/ダイス か、そのまま書き込みます。ダイス・技能判定・成功判定・電卓を、書き方から自動で見分けます。

書き方できること
1d100 2d6+3ふつうのダイス・計算つきのダイス
80 目星 80目星2 桁の技能値と技能名で判定（クリティカル・ファンブル・1/2・1/5 も出ます）
1d100<=60 #目星目標値つきの成功判定。技能名は #目星 【目星】 の形で付けられます
1d100>80 【目星成長】不等号の判定（<= < >= >）
1d3*2+2*(4+5) 1+1四則演算・括弧・ダイスの計算。電卓にも使えます
d66D66（6 面ダイス 2 個を 2 桁の数字に）
res50-30対抗ロール（能動側 50・受動側 30）
siz13SIZ の値から身長のめやすを出します

/ダイス は、式: を省くと 1d100 を振ります。

ヒントアルファベットと空白は、半角・全角のどちらで打っても振れます。80目星 のように空白なしで続けられるのは、日本語など全角で始まる技能名です（英語なら 80 spot のように空白を入れます）。

Bot に話しかける（おしゃべりモード）

  • @Macchan ～？ … 「そうかも」「違うかも」と答えます
  • こんにちは・おやすみ・またね などの挨拶 … 挨拶を返します
  • そのほか … ダイスをコロコロします

3こっそり振る（秘匿ロール）

ダイスの頭に s を付けるか、/シークレット を使うと、結果を振った本人にだけ届けます。

  1. s1d100 s80 目星 s1d100<=60 #目星 のように書き込みます（内容を隠すため、書き込みは消えます）。/シークレット 内容: でも振れます。ダイスでない文を入れると、秘密のメッセージになります。
  2. チャンネルに「〇〇さんの秘匿ロールがあります」と通知が出ます。結果は本人にだけ届きます。
  3. 公開したくなったら、通知の 🔓 公開する を押します。結果がチャンネルに出ます。
ポイントボタンを押せるのは振った本人だけです。ほかの人が押しても、その人に「振った本人だけが使えるボタンです」と出るだけです。

結果の届け方は、サーバーごとに選べます

Macchan Bot コンソールの「秘匿ロール」→「結果の届け方と公開のしかた」で選びます。

チャンネルのボタンで公開
最初はこれ		結果は DM に届きます。公開はチャンネルの 🔓 公開する で行います。
DM を使わないDM には送らず、チャンネルの 👁 結果を見る を押すと本人にだけ表示されます（何度でも見られます）。/シークレット で振ったときは、すぐに本人にだけ表示されます。
DM の 🔓 で公開以前の形です。結果は DM に届き、DM に付いた 🔓 を押すと公開されます。

DM を閉じている方でも、「チャンネルのボタンで公開」のときは自動で「DM を使わない」形になるので、そのまま振れます。

4ほかのシステムで振る（BCDice）

BCDice のダイスに対応しています。ココフォリアなどで使われているものと同じコマンドで振れます。どのプランでも無料です。

何も設定しなくても振れるコマンド

ほかのシステムと被らない代表的なコマンドは、どのシステムかを自動で見分けて振ります。結果の下には「ダブルクロス（自動）」のように、振ったシステムが出ます。

書き方振るシステム
3B6 3R6 3U6 C(1+2) x3 2d6どのシステムでも同じ（汎用ダイス）
CCB<=60 RESB(10-5)クトゥルフ神話TRPG（6 版）
CC<=60 CC(1)<=60 CBR(50,60)新クトゥルフ神話TRPG
K20+5@10ソード・ワールド2.5
10DX+3@8ダブルクロス
1NC NM永い後日談のネクロニカ
SG>=5 MTシノビガミ
4SK HOT銀剣のステラナイツ
ATマギカロギア

ST（シーン表）DT FT BT RTT などはシステムによって中身が違うため、自動では振りません。下の「システムを選ぶ」で選んだチャンネルか、/ダイス の「システム」を選んで振ってください。1d100<=60 や 80 目星 など Macchan がもともと読める書き方は、これまでどおり Macchan の判定で返します。

振り方の例

  • CC<=60 目星 … 新クトゥルフの技能ロール → 【目星】ハード成功
  • K20+5@10 #ナイフ … ソード・ワールド2.5 の威力表
  • ST … シノビガミ・インセインのシーン表（システムを選んだチャンネルで）
  • sCC<=40 … 頭に s を付けると秘匿ロールになります

技能名は、空白のあとや #目星 【目星】 の形で付けられます。

システムを選ぶ サーバーの管理者

Macchan Bot コンソールの「ダイスシステム（BCDice）」で選びます。

このサーバーで使うシステムサーバー全体で使うシステムを 1 つ選びます。最初は「選ばない」です。名前の一部や英語名で探せます。
システムを選んでいないとき「代表的なコマンドを自動で見分ける」（最初はこちら）か「Macchan のダイスだけ」。ほかのダイスボットと反応が重なるときは「Macchan のダイスだけ」にしてください。
チャンネルごとに変えるCoC の卓とソード・ワールドの卓が同じサーバーにあるときは、チャンネルごとに別のシステムを選べます。スレッドでは、親のチャンネルのシステムが使われます。
Macchan のダイスと重なったときMacchan のダイスを先に見る（おすすめ）… これまでどおりの表示で、CC K20 など Macchan が知らないコマンドだけを BCDice で振ります。
BCDice を先に見る … 1d100<=60 も、そのシステムの判定（新クトゥルフならハード成功など）で返します。

よく使うシステムは一覧の上に並んでいます：クトゥルフ神話TRPG / 新クトゥルフ神話TRPG / ソード・ワールドRPG / 2.0 / 2.5 / シノビガミ / インセイン / ダブルクロス The 2nd・3rd Edition / 永い後日談のネクロニカ / マギカロギア / 銀剣のステラナイツ / フタリソウサ。ほかにも BCDice にある 300 以上のシステムから選べます。

ヒントコマンドの書き方はシステムごとに違います。/ダイス 式:help と打つと、そのチャンネルのシステムの使い方が自分にだけ表示されます。/ダイス の「システム」を選べば、システムを選んでいないチャンネルや DM でも、どのシステムでも振れます。

6自分の表を作る（マイ表）

自分だけの表を登録して、/マイ表 や表の名前を打つだけで振れます。

  1. Macchan Bot コンソール の「マイ表」で、表を作ります。
  2. 表の名前をそのまま書き込むか、/マイ表 表: 回数:（1〜10 回）で振ります。
  3. 管理権限のあるサーバーに「設定」すると、そのサーバーではほかの人も振れます。
  • 表は「作った人のもの」です。マイアプリに追加すれば、Bot のいないサーバーや DM でも振れます。
  • 一時的狂気 不定の狂気 冬の狂気 おみくじ 誕生日 と同じ名前にすると、組み込みの表の代わりにマイ表が振られます（ハウスルールの狂気表などに）。
  • 項目の頭に 【秘】 を付けると、その項目が出たときは結果が振った人にだけ届きます。||ここ|| で囲めば、その部分だけを伏せられます。届け方は秘匿ロールの設定と同じです。
  • 結果に @サーバー主 と書くと、表を作った人に通知が届きます。
  • 同じサーバーに、同じ名前の表を 2 つ設定することはできません。
無料1 表・1 表につき 10 項目・1 項目 100 字まで
有料 PRO10 表・500 項目・2,000 字まで（登録できる数は 1 人あたり）

支援が終わっても表は消えません。使えるのは、いちばん古く作った 1 表だけになります（残りは止まるだけで、支援に戻ればまたすべて使えます）。

7探索者を作る・登録する

能力値を振って探索者を作れます。登録しておけば、技能名を打つだけで自分の技能値で判定できます。

能力値を振る

/キャラ作成 か、キャラ作成（PC作成 キャラ生成）と書き込みます。CoC 6 版の能力値を振り、ココフォリアの駒に出力することもできます。

キャラクターを登録する

  1. キャラクター登録のページ を開き、Discord でログインします。管理権限は要りません。卓のみなさんにこの URL を配ってください。
  2. いあきゃら や キャラクター保管所 の 「ココフォリア用に出力」 を貼ります（ココフォリアで駒をコピーしたものは、名前しか入りません）。
  3. 読み取った技能と能力値が出るので、確かめて登録します。
  4. 名前の一覧の右で、使うサーバーを付けます。
  • 登録したキャラクターは「ストック」に入ります。サーバーに付けていないキャラクターがあっても大丈夫です。
  • 1 つのサーバーで使えるのは 1 人 1 体です。同じキャラクターを複数のサーバーに付けることもできます。
  • 同じ名前のキャラクターを貼ると入れ替わります。ストックは無料が 1 体、PRO の方が 5 体までです。PRO が切れて 30 日たつと、1 体を超える分は消えます（いちばん古く作った 1 体は残ります）。
  • 付けられるのは、あなたが管理権限を持つサーバーです。「マイアプリ」に付けると、Bot のいないサーバーや DM でも /マイキャラ で使えます PRO。

振る・ステータスを動かす

書き方できること
目星技能名だけで、登録した技能値で判定。芸術 のように候補が 2 つ以上あるときは聞き返します
目星-20 目星+10 目星/2その場だけの補正（保存はしません）
:HP-3 :SAN-1d3 :MP+2HP・MP・SAN を増減。最大値を超えず、0 より下にもなりません。SAN を減らすと、SAN を見る判定も下がります
/マイキャラ 入力:コマンドでも同じことができます（/マイキャラ HP-3 のようにコロンは要りません）。入力を省くと、いまのステータス・能力値・技能を自分にだけ見せます

HP・MP・SAN の増減はキャラクター本体に反映されます（付けているどのサーバーでも同じ値です）。キャラクターを外すときは、/個人設定 で出るリンクから登録のページを開きます。

ご注意技能名は、おみくじなどの表より先に見ます。表と同じ名前の技能を持っている方は、技能のほうが振られます。ほかのダイスボットとぶつかるときは、サーバーの設定からメッセージ入力だけを切ることもできます（/マイキャラ は使えます）。

8VC とチャンネルの操作

卓の部屋への出入りや、VC の切断・ミュートをまとめて扱えます。

コマンドできること
/入室 相手: /退室 相手:指定した人を、この部屋に入れたり外したりします（相手の操作は要りません）
/ボイス 解散自分がいる VC の全員を切断します
/切断 相手:指定したメンバーを VC から切断します（英語名は /nero）
/ボイス 秘匿 操作: 相手: ボイスch:秘匿ボイス。相手を指定するとその人だけ、省略すると VC の全員に効きます。ボイスch: を省くと自分がいる VC が対象です
/パネル お誘い押した人が指定チャンネルに入れる「お誘い」を置きます
/パネル ロール押すとロールが付く「ロールパネル」を作ります

VC の操作には、Bot に「メンバーを移動」の権限が要ります。チャンネルの閲覧権限やロールを扱うものには、それぞれ「チャンネルの管理」「ロールの管理」の権限が要ります。

自動でうごく機能

どれも Macchan Bot コンソール で、対象の VC や出し先を決められます。

🔔 VC お知らせVC で通話が始まると、お誘いの通知を出します（終わったときも）。通知先は「ひとつのチャンネルにまとめる」「VC ごとに決める PRO」「VC と同じ名前のチャンネル」から選びます。対象の VC は「記号で選ぶ（既定は 🔔）」「選んだ VC だけ」「すべての VC」。開始時のメンション（@everyone / @here / ロール / なし）と、終了の通知も選べます。
🕛 おやすみ通知深夜 0 時、対象の VC にいる方へおやすみのお知らせを出します（既定は 🕛 の記号で選ぶ）。
💤 自動で解散決めた時刻（既定 2:00・日本時間）に、対象の VC の全員を切断します。5 分前に予告し、⏰ を押すと 30 分延ばせます（1 晩に 2 回まで）。最初は切ってあります。

何も設定していないサーバーでは、「名前に 🔔 が付いた VC」の通話が「🔔ボイチャお知らせ」という名前のチャンネルに @everyone 付きで届きます。PRO が切れても「VC ごとに決める」の対応表は消えません（いったん「まとめる」の動きに戻るだけです）。

9リマインド・休憩 PRO

決めた日時に、このチャンネルで知らせます。PRO のサーバーか、PRO の方ならどこでも使えます。

コマンドできること
/リマインド 予約 日時: 内容:日時は 明日 21:00 10/15 21:00 30分後 来週 などで書けます。Bot のいないところでは DM に届きます
/リマインド 休憩 時間:「21:30まで休憩です。」を出し、時間になったら「開始時刻になりました。」と知らせます。30 分以上なら 5 分前にも知らせます
/リマインド 一覧自分の予約を見て、取り消します

送る文はコンソールで変えられます。

10卓の日程を決める（卓日和）

卓の日程決めとメンバー募集の機能です。Discord の中から始められて、答える人はブラウザで丸を付けるだけです（ログイン不要）。

/日程作成 名前:11月の卓 メンバー:@まちゃ けん さくら 開始日:11/9
  • 公開用の URL がチャンネルに出ます。主催者用の URL は、実行した方にだけ届きます。
  • /個人設定 で、キャラクターと日程調整の「自分の設定」のページを開けます。
卓日和の使い方ガイドへいつごろかを聞く・メンバー募集・シナリオの候補・公開カレンダー・フォローなど、くわしい使い方はこちら見る →

11サーバーの設定

サーバーの管理者

機能ごとに ON / OFF と「誰が使えるか」を決められます。

  1. Macchan Bot コンソール を開き、Discord でログインします（「サーバーの管理」権限が要ります）。
  2. サーバーを選ぶと、機能の一覧が出ます。スイッチで ON / OFF、詳細 で「反応するもの」「使える人」や機能ごとの設定を変えて、保存する を押します。
  • ほかのダイスボットと反応がぶつかるときは、重なっている機能だけを切れます。メッセージ入力のダイスだけ止めて /ダイス は残す、といった使い方ができます。
  • ダイスシステム（BCDice）のシステム選びと、秘匿ロールの届け方もここで決めます。
  • いまの設定は、Discord で /サーバー設定 を打つと確かめられます。

有料プランは 2 種類あり、付く先が違います。

?困ったとき

書き込んでもダイスに反応しない
サーバーの設定で「ダイス」が OFF か、「/ダイス だけ」になっているかもしれません。/サーバー設定 で確かめてください。/ダイス はいつでも使えます。
ほかのダイスボットと二重に反応する
コンソールで、重なっている機能のメッセージ入力だけを切ってください。BCDice の自動の見分けは「システムを選んでいないとき」を「Macchan のダイスだけ」にすると止まります。
ST（シーン表）が振れない
ST はシステムによって中身が違うので、システムを選んだチャンネルでだけ振れます。/ダイス 式:ST システム:シノビガミ のように「システム」を選んでも振れます。
秘匿ロールの結果が見られない
DM を閉じていると DM には届きません。チャンネルの通知に 👁 結果を見る があれば、そこから見られます。
技能名を打ったら、表ではなく技能が振られた
キャラクターを登録していると、技能名を表より先に見ます。探索者を作る・登録するをご覧ください。
